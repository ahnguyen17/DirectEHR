# Tech Context

**Technologies Used:**
- React: JavaScript library for building user interfaces.
- React Router: Declarative routing for React.
- Vite: Fast development build tool.
- Tailwind CSS: Utility-first CSS framework.
- Node.js and npm: JavaScript runtime and package manager.

**Development Setup:**
- Project is set up with Vite.
- Dependencies are managed with npm.
- Development server is started with `npm run dev`.

**Technical Constraints:**
- Currently, data persistence is not implemented (placeholder pages created).
- Error handling and validation may need to be added.

**Dependencies:**
- Dependencies are listed in `package.json`.

**Tool Usage Patterns:**
- `npm install` for dependency management.
- `npm run dev` for starting the development server.
- Use of `write_to_file` to create new files.
- Use of `read_file` to examine existing files.
- Use of `execute_command` to run terminal commands.
- Use of `browser_action` to interact with the running application in a browser.
